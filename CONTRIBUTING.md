# Contributing

Keep the benchmark reproducible, synthetic, and auditable.

1. Create a focused branch.
2. Keep financial posting and approval actions outside the agent boundary.
3. Add or update tests for matching, controls, or KPI behavior.
4. Run `pytest -q` and the hosted-dashboard build before opening a pull request.
5. Label simulated ERP structures and benchmark results clearly; never imply genuine vendor integration or customer impact.

Changes to tolerances, exception routes, KPI definitions, or agent authority should include the corresponding configuration, traceability, UAT, and documentation updates.
